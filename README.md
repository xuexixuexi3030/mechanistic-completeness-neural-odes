# Mechanistic completeness and physics integration in neural ODEs

This repository is the public project entry for the manuscript **Mechanistic completeness and physics integration in neural ODEs**.

## Current release

This is a **README-only release**. Training source code, checkpoints, individual run files, and unpublished manuscript files are not included in this public repository at this stage.

The manuscript appendices document the experimental settings, computational accounting, aggregate results, and local sensitivity checks. The benchmark compares PINN, Neural ODE, MC-NODE, PG-NODE, and MA-NODE on synthetic gene-regulatory and eco-epidemic systems.

The reported evidence includes 200 native benchmark runs, 59 historical ablation/control records, and 216 matched-control runs. Historical continuations and matched implementation labels are not additional independent seed replications.
